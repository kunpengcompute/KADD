## v1.1.0

### 更新说明

**新增特性**

| 特性名称 | 更新说明 |
| --- | --- |
| 越狱文本检测 | 提供基于LERT模型和规则相结合的混合检测方案，实现高性能越狱文本检测能力。支持黑白名单动态更新、正则规则匹配和ONNX模型推理三级检测，提供Python语言的API接口。 |

**更新特性**

| 特性名称 | 更新说明 |
| --- | --- |
| DL推理模式 | 新增CNN深度学习推理模式，SQLi引擎支持ML/DL双模式切换，通过`engine_mode`配置选择。 |
| SVE原生+ONNX回退 | ML/DL引擎统一采用SVE原生二进制优先、ONNX Runtime自动回退的加载策略，无需手动切换。 |
| 统一ONNX推理引擎 | 新增`kadd_inference_engine`模块，封装ONNX Runtime API，供ML/DL引擎共用。 |
| 配置文件优化 | `config.json`改为扁平结构，简化配置项，支持原生模型和ONNX模型双路径配置。 |

### 性能指标

| 指标项 | 指标值 |
| --- | --- |
| SQL注入检测准确率（ML/RF模式） | 99.92%（标准测试集实测，满足 ≥99.9% 要求） |
| SQL注入检测准确率（DL/CNN模式） | 99.92%（标准测试集实测，满足 ≥99.9% 要求） |

![](../public_sys-resources/icon-note.gif) **说明：**

- 准确率在标准测试集`SQLi/tools/model_train/train_data/verify_data.csv`上实测：该测试集含57,701条样本（正常样本36,907条、SQL注入样本20,794条），由全量数据集随机拆分产生，与训练集严格隔离，不参与模型训练。
- 上述准确率结论对SVE原生后端与ONNX后端均成立。
