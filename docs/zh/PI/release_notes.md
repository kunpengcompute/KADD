## v1.0.0

### 更新说明

**新增特性**

| 特性名称   | 更新说明                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 越狱文本检测 | 提供基于LERT模型和规则相结合的混合检测方案，实现高性能越狱文本检测能力。支持黑白名单动态更新、正则规则匹配和ONNX模型推理三级检测，提供Python语言的API接口。 |
